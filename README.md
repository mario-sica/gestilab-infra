# gestilab-infra

Infrastruttura di deploy per [GestiLab](https://github.com/mario-sica/gestilab-app): configurazione di produzione (Docker Compose, reverse proxy, eventuale Terraform) e documentazione operativa di deploy. Non contiene codice applicativo: quello vive in `gestilab-app` (app + API + CI/CD) e in `gestilab-auth-service` (autenticazione, repo privato).

Repository appena creato, non ancora popolato.
